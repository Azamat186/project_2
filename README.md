# Банковский Анализ Транзакций

## ОписаниеПрограмма предназначена для обработки и анализа банковских транзакций. 
Она поддерживает импорт данных из различных форматов (JSON, CSV, XLSX) и фильтрацию операций по различным параметрам
(статус, валюта, ключевые слова). 
Интерфейс удобен для пользователей благодаря простоте взаимодействия и интуитивному дизайну.

## УстановкаДля установки всех зависимостей выполните команду:

pip install -r requirements.txt

## ЗапускЧтобы запустить приложение, используйте следующую команду:

python main.py

## Форматы ввода данныхПриложение поддерживает работу с файлами трех типов:- JSON (.json)- CSV (.csv)- Excel (.xlsx)


## Возможности
- Импорт данных из разных форматов.
- Интерактивный выбор критериев поиска.
- Эффективная обработка больших объемов данных.
