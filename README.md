# Проект: 13.1 Библиотеки `csv` и `pandas`

## Описание проекта

Учебный проект «13.1 Библиотеки csv и pandas» — практическое руководство по работе с табличными данными в Python. 
Он помогает освоить два основных подхода к обработке CSV‑файлов: с помощью стандартной библиотеки 
`csv` и мощной библиотеки `pandas`.

Проект предназначен для начинающих Python‑разработчиков и аналитиков данных, которые хотят:
* понять базовые принципы работы с данными;
* научиться выбирать инструмент для конкретной задачи;
* увидеть разницу в подходах и оценить преимущества каждого метода.

## Цели и задачи

**Основная цель:** сформировать навыки чтения, записи и базовой обработки данных в формате CSV.

**Задачи проекта:**
* изучить работу со стандартной библиотекой `csv`;
* освоить основные операции с `pandas` для работы с данными;
* сравнить эффективность и удобство двух подходов;
* получить опыт написания чистого кода для обработки данных;
* научиться правильно настраивать параметры чтения/записи файлов (кодировка, разделители и т.д.).

## Целевая аудитория

Проект будет полезен:
* начинающим Python‑программистам;
* студентам курсов по анализу данных;
* аналитикам, переходящим на Python с других инструментов;
* всем, кто работает с табличными данными и хочет автоматизировать рутинные операции.

## Используемые технологии

* **Python** (версия 3.6+);
* стандартная библиотека **`csv`** — для базового чтения и записи CSV‑файлов;
* библиотека **`pandas`** — для продвинутой обработки и анализа данных;
* формат данных **CSV** (Comma‑Separated Values) — универсальный формат для табличных данных.

## Установка зависимостей

Библиотека `csv` входит в стандартную поставку Python, её не нужно устанавливать отдельно.

Для установки `pandas` выполните: pip install pandas


## Примеры использования
1. Работа с модулем csv
# Чтение CSV‑файла
python

import csv

with open('data/data.csv', mode='r', encoding='utf-8') as file:
    reader = csv.DictReader(file)
    for row in reader:
        print(f"{row['name']} из {row['city']}, возраст: {row['age']}")


# Запись в CSV‑файл
python

import csv

data = [
    {'name': 'David', 'age': 28, 'city': 'Paris', 'salary': 55000},
    {'name': 'Eve', 'age': 32, 'city': 'Berlin', 'salary': 62000}
]

with open('output/output_csv.csv', mode='w', encoding='utf-8', newline='') as file:
    writer = csv.DictWriter(file, fieldnames=['name', 'age', 'city', 'salary'])
    writer.writeheader()
    writer.writerows(data)

# Фильтрация и сохранение результатов
python
import pandas as pd

# Читаем данные
df = pd.read_csv('data/large_data.csv')

# Фильтруем: люди старше 30 с зарплатой > 60 000
filtered_df = df[(df['age'] > 30) & (df['salary'] > 60000)]

# Сохраняем результат
filtered_df.to_csv('output/filtered_data.csv', index=False)
