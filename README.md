# 13.1 Библиотеки `csv` и `pandas`

Этот раздел посвящён работе с табличными данными в Python с использованием стандартной библиотеки `csv` 
и популярной библиотеки `pandas`.

## Цель

Научиться:
* читать и записывать CSV‑файлы с помощью модуля `csv`;
* выполнять те же операции более эффективно с помощью `pandas`;
* сравнивать подходы и понимать, когда какой инструмент предпочтительнее.

## Установка зависимостей

Библиотека `csv` входит в стандартную поставку Python, её не нужно устанавливать отдельно.

Для установки `pandas` выполните:
